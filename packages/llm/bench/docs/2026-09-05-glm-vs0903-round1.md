## 收敛发现（三组独立复盘交叉验证）

### LLM 侧失分模式（按影响排序）

1. **几乎不卖货（头号分差来源）**：卖动占比 ~4% vs 启发式 10-19%；3 局零卖单
   （5016 三座卖货板块 £45 砸手里 0 VP；5023/5027 同样 0 卖）；30 局 0 次建棉纺；
   无买家煤矿/无人喝酒厂/卖不出的陶瓷反复出现，约 20-50VP/局 挂在场上计 0。
   决策理由反复出现错误信念「运河时代不碰消费板块/不压死现金」。
2. **贷款理由与执行脱节（5/10 局致灾）**：贷款时宣称「下步建铁厂当场翻面转正」，
   实际却建「卖出才翻面」的煤矿/酒厂，收入拖到 -3~-6，运河期全程失血
   （a0 头号死因；a2 的负收入贷款四局同象）。
3. **终局自毁**：倒数 1-2 动建「卖出才翻面」板块零回报（5022 seq122、5026
   seq102、5029 seq120，各烧 £10-16）；末位贷款（5023/5025/5027）；资金堆积
   （5028 终局 £126 作废、收入 46 全场最高却垫底）。9-10/10 局 R15-R16 出现
   研发/贷款/为下回合铺垫类无效动作，每局浪费 5-10VP。
4. **规则幻觉**：Develop 直接拿 VP、已翻面酒厂可供啤酒、引用不存在的手牌
   （5012/5013/5014/5016 seq70）。
5. **煤矿过量/低 VP 循环**：4-7 座煤矿/局（5027 达 7 座），5029 收入 75 全场最高
   仍垫底——收入堆上去不转成 VP。

### 启发式（0903）侧缺陷

1. **尾部风险**：5004 破产 0 分证明「深研发无经济门槛 + 负收入贷款」可致灾难；
   收入地板（deep -7 / debt -4）放得太宽。
2. **终局现金滞留**：£28-£107 未花反复出现（5007 冠军只赢 1 分）——终局现金
   不折 VP，富有罚分（30/42/55 三档）压低了「贷款→当场翻面建」的转化。
3. **搜寻过度**：非缺牌场景搜寻（5020 P1、5028 P3 因此掉出前二）——每回合
   tempo 价值 ~2VP，maxRefresh 5.0 偏高。
4. 复盘工具注意：trace 的 chosenRank 锚的是 prescreen 轻量评分器（LLM 候选
   排序用），不是 0903 插件内部 CFG 评分——「冠军选了 rank 50-225 动作」说明
   prescreen 与插件评分有出入，改善 prescreen 属于【LLM】候选质量方向，
   而非 0903 本体。
