## 下一轮迭代清单（按预期收益排序，均建议机制化而非 prompt）

1. **可卖性/售路进状态摘要与 prescreen**：建消费板块前的「连通商人 + 啤酒 +
   行动位」三要素目前靠模型自觉；把每块己方未翻可售板块的「能否卖/缺什么」
   写进状态摘要，卖出预约才可执行（当前最大单一 VP 漏损）。
2. **煤矿配额下沉 prescreen**：区分即时矿（建成即卖市场，白名单）/延迟矿
   （限额 2）；prompt 软约束已被证实无效。
3. **贫瘠候选窗的 pass 出口**：终局候选消毒后候选贫瘠时模型连 pass 丢行动位
   （5018 手握 £29 双 pass）——prescreen 需强制注入「£3 运河/当场翻面建造」
   类即时兑现出口。
4. **降级 fallback 安全下限**：5008 的 API 降级走了启发式 rank63 负收入贷款
   （-2→-5），是全组最大单点伤害；降级路径应复用候选消毒。
5. **贷款/负收入判定算术化**：贷款理由要求逐字引用含「建成即翻」的候选，
   防理由与执行脱节（a0 头号死因，v5/v6 有改善但未根除）。

## 结论

- LLM 侧三轮迭代把 GLM-5.3-Flash 从 75.2 → 80.7（+7.3%），失败模式从
  「破产/崩盘」收敛为「稳定中游」；与 0903（内战 114）仍有 30+ 分差距，
  差距主体已从「自毁」转移到「上分效率」（卖货闭环率、铁路期剧本）。
- 方法论：同种子三轮对照 + 逐局复盘 + 假设/验证/否决全记录，prompt 层
  改动收益有限且概率性遵守，**候选过滤层与状态摘要层的机制化改动是
  确定性收益**（终局消毒 10→0、延迟标签、prescreen 贷款对齐）。
