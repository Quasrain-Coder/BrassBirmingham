# jsb-v20260907：IS-MCTS（信息集蒙特卡洛树搜索）方案与验证

日期：2026-09-07 ｜ 基线：jsb-v20260903 ｜ 状态：n=100 达标（vs 0903 63%、内战均分 122+）

## 1. 动机

0903 及之前的版本是纯启发式：行动分（scoreOp）+ 2-ply 前瞻 + 局面叶估值
（evaluatePosition）。ES 坐标下降对 12 个权重调参两轮 sweep，确认权重空间已是
局部最优（微调权重 vs 0903 仅 ~53%，内战均分反而下降）。进一步提升需要换
决策框架：对难决策用采样模拟代替静态估值。

## 2. IS-MCTS 概念

标准 MCTS 假设全知局面；伯明翰有隐藏信息（对手手牌、牌库顺序），上帝视角
模拟等于作弊。IS-MCTS（Information Set MCTS）的解法：**每次模拟前先做一
次确定化（determinization）**——按公开信息重采一个与已知信息一致的"平行
世界"，在该世界中模拟，统计量对所有平行世界取平均，天然建模隐藏信息。

旧版被证死的扁平 UCB1（mctsSimulations）三短板：上帝视角不确定化、纯随机
推演（与真实对局相关性太弱，实测 90 vs 128 VP）、只看终局 VP。0907 逐项
修正：确定化 + 启发式引导推演 + 局面叶估值。

## 3. 实现（heuristic-core.ts，约 120 行）

### 3.1 determinize(state, pid, rand) — 信息集确定化

- 未知牌集合 = `buildDeck(playerCount)` − 我方手牌 − 弃牌堆（对局中全程公开，
  视为已知信息）；
- 百搭牌不在牌库集合：对手可能持有的百搭 = 供应堆流出量（`wildSupply` 公开）
  − 我方手牌/弃牌中的百搭，按张补进未知池；
- Fisher-Yates 洗牌后，按各对手当前手牌数依次重发，余下作新牌库；
- 我方手牌、盘面、市场、rngState 等其余状态不变（根动作在我方手牌不变下
  必合法）。

### 3.2 guidedRollout(state, pid, rand) — 引导推演

- 从根动作后的局面最多打 `rolloutPlies`（24）步（≈3 轮），全体玩家共用同一
  策略：90% 概率按 1-ply 启发式贪心（scoreLegal 第一名），10% ε-随机（防止
  同一确定化下轨迹全同，提供走法多样性）；
- 提前终局：返回我方真实 VP；否则：返回 `evaluatePosition(endState, pid)`
  （0903 同款叶：真实翻面概率折算未翻板块 VP + Link 图标分 + 现金/收入折算
  + 手牌灵活性）。

### 3.3 ismctsChoose(state, pid, ranked) — 根选择

- 根候选 = 2-ply 价值前 `topK`（4）名；
- `simulations`（40）次迭代：UCB1 选根（均值 ÷ `valueScale`(200) 归一 +
  `c`(1.0)×√(lnN/ni)，有前景的候选自动分到更多模拟）→ 新确定化 → 应用
  根动作 → guidedRollout → 累加；
- 取均值最高的候选。

### 3.4 难决策门控（chooseAction 内）

- 仅当 2-ply 前两名价值差 < `gateMargin`（3.0）时触发 IS-MCTS；差距明显时
  直接信任启发式——约一半决策不触发，算力集中在真正的岔路口。

### 3.5 可复现性

模拟随机数用 LCG（种子 = CFG.ismcts.seed ⊕ round ⊕ state.rngState），
同一局面必然出同一决策，回放/复盘可复现；不用 Math.random、不用墙钟。

## 4. 成本

| 项 | 值 |
|---|---|
| 单步启发式决策 | ~0.08s |
| 单次模拟（确定化 + 24 步推演 + 叶估值） | ~100-150ms |
| 单次触发（40 模拟） | ~4-6s |
| 单局（约 30-50% 决策触发） | ~180s（纯启发式 ~10s） |

降预算旋钮：simulations / rolloutPlies / gateMargin（未做成本-效果扫参）。

## 6. 已知近似与后续方向

- 推演中所有玩家共用同一启发式（不追踪各对手研发计数、风格差异）；
- 确定化假设弃牌堆全量公开（与真人玩家记忆一致），不建模对手对彼此手牌
  的推断（单观察者视角 SO-ISMCTS）；
- 未做：模拟预算-胜率扫参、树结构（当前为根层扁平 UCB1）、推演策略与
  主启发式的差异化。
