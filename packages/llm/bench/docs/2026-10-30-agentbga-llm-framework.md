# AgentBGA 风格 LLM 框架与对局评估（2026-10-30）

## 框架能力

- **统一决策适配**：当前座位观察、完整合法动作和稳定动作 ID 均来自本项目引擎；模型只提交合法 ID，不另写规则引擎。
- **多轮工具调用**：提供 `observe`、`legal_actions`、`inspect_rules`、`inspect_history`、`read_notes`、`write_notes`、`submit_action`；系统提示仅包含游戏名、座次和工具说明，不预置棋理。
- **隐藏信息隔离**：当前座位可见完整手牌，对手仅暴露手牌数，不暴露牌序或随机状态。
- **协议与可靠性**：支持 OpenAI Chat Completions 与 Anthropic Messages；记录 token 用量，支持错误重试、无请求超时模式及禁止降级模式。凭据与网关地址均由运行环境提供，不写入仓库。
- **终局推理回放**：保存每次模型响应的推理原文、可见文本和工具名；实时对局只落库，不广播、不允许读取、导出时剥离。终局后按 AI 座位读取，个人版图“思路”按钮逐动展示全文，支持在线终局和导入回放。

## 单步真实响应验证

k3.1pro 完成一次合法建造决策：4 轮工具调用，保存 42,886 字符推理原文，耗时 197.5 秒，未降级。
