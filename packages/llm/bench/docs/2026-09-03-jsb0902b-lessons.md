# Brass: Birmingham 战术复盘（jsb-v20260902b 四人自对局）

## 一、开局（运河时代 C1–C3）：强 AI 的共性序列

两局开局高度收敛，可提炼出固定模板：

1. **第一动研发拆两个 1 级酿酒厂**（两局 P0 步 0 均如此；其余玩家在 C1–C3 内跟进，如 A 局 P1 步 6、P3 步 8，B 局 P2 步 8）。2 级酿酒厂 £7+1铁 → 5VP+5收入+2Link，是运河时代单位成本收入效率最高的板块，且为铁路时代双轨储备啤酒。
2. **首条运河必连商人**：`coalbrookdale-shrewsbury` 两局都是全局第一批铺设（A 步 4、B 步 2）；`stoke-on-trent-warrington`（A 步 10、B 步 4）紧随其后。**先修通商人通道，再造可卖货物**，顺序不能反。
3. **Coalbrookdale 铁厂开局**：1 级铁厂 £5+1煤 → 翻面 3VP+3收入，**建成即卖市场回收 £6–10**（A 步 5/9、B 步 5/9/17）。铁厂在开局是"印钞机"而非 VP 来源，卖市场的现金回流支撑后续 £7 酒厂、£12 棉纺的连建。
4. **配套 1 级煤矿**（A 步 7/23、B 步 10/23）：£5 换 1VP+4收入+2Link，顺便卖煤回血 £2–3。

典型前三轮序列：**研发酒厂 → 铺运河连商人 → 铁厂即卖 → 煤矿 → 2 级酒厂 ×2**（A 局 P0/P1、B 局 P0 均按此展开）。

## 二、中期（C4–C8）：收入轨道与翻面节奏

1. **收入推进主力是 2 级煤矿**：£7 换 2VP+**7收入**，全场出现 8+ 次（A 步 45/60/64/75，B 步 29/51/53/54/67/74/77）。胜者终局收入等级均达 14–16（B 局 P2/P3 末段贷款前收入 12/16），折合终局 14–16 VP。
2. **1 级陶瓷厂是中期 VP 爆点**：£17+1铁 → 10VP+5收入，且人人抢建并**必卖到商人**（A 步 12→13、77→89；B 步 79→87、90→91）。这是单板块最高基础 VP。
3. **C6–C8 密集研发制造厂**：A 局 P1 三步研发冲到 7 级（步 50–52），B 局多家冲到 4–5 级（步 30/33/42/47/48/55）——为铁路时代 7/8 级制造厂（9–11VP）预埋解锁。
4. **贷款时机的分水岭**：
   - 安全贷款：收入 ≥5 时贷（A 步 43：5→2；步 62：9→6；步 83：11→8），贷后仍为正，无惩罚。
   - 危险贷款：日志明确标注"禁止"的负收入贷款。B 局 P0 是反面教材：步 11（2→-1）、步 28（**-1→-4**，负上再贷）→ 终局 92 分全场最低。A 局虽全员 R1 负贷，但**只贷一次且立刻用铁厂/酒厂转正**，之后再不负贷。

## 三、铁路时代：转型信号与分水岭

1. **R9 首轮即铺双轨**（£15+2煤+1酒，酒源优先自产酒厂）：A 步 61/63/74、B 步 60–61（P2 一轮连铺两条双轨）。这是铁路时代的标准开场，一口气补 4 个连通。
2. **高级铁厂继续即建即卖**：3 级 £11、4 级 £15–21（A 步 90 卖 £21、步 96 卖 £15），现金引擎贯穿全场。
3. **高分玩家的标志性动作——一次行动双卖**：B 局 P2 步 87 同时卖出陶瓷厂+3级棉纺厂至 oxford 商人，单次 **19VP+8收入**，是该局 122 分夺冠的胜负手。普通玩家（B 局 P0/P1）整局无双卖。
4. **分水岭数据**：
   - 胜者：所有高价板块**全部有对应卖出记录**；终局收入 12–16；铁路时代至少 2 条双轨。
   - 败者 B-P0（92）：C6–C8 花 3 步研发制造厂到 5 级，建成 5 级制造厂（步 84）和 1 级陶瓷厂（步 105）后**均无卖出记录**——研发成本和建造成本全部沉没，且少了 18VP 翻面收益。这是 92 vs 122 的直接原因。

## 四、终局（R13–R16）：收官特征

1. **高收入末段贷款零成本套现**：收入 14→11、16→13、15→12（A 步 110/123，B 步 92/115），终局收入已无需再经营，-3 换 £30 投最后两个板块稳赚。
2. **补铺铁路刷 Link VP**：R14–R16 大量"新连通无"或单连通的 £5 铁路（A 步 106–121、B 步 114–120）——赌时代末 Link 计分。
3. **2/3 级煤矿收尾**：£7–8 换 +6~7 收入（≈终局 6–7 VP），是最后两轮性价比最高的动作（A 步 103/114/117/122、B 步 93/96/104/113/121）。
4. **7/8 级制造厂压轴卖出**：11VP+商人奖励（A 步 104→105，B 步 110→111），通常留到最后 2–3 轮打出。

## 五、写给 LLM 玩家的 7 条经验法则

1. **开局固定三板斧**：第一动研发拆两个 1 级酿酒厂；第一/二动铺运河连最近商人（优先 `coalbrookdale-shrewsbury`，其次 `stoke-on-trent-warrington`）；随后在 Coalbrookdale 建 1 级铁厂并立即卖市场回收现金。（依据：两局 8 个席位中 7 个在 C1–C3 内完成酒厂研发；两条商人运河均为全局前 10 步铺设；铁厂建成即卖在两局共出现 6 次，回收 £6–10/次，直接支撑后续 £7 酒厂、£12 棉纺的连建。）

2. **铁厂/煤矿是"现金流引擎"而非计分器**：运河时代建铁厂（1 级 £5、3 级 £11、4 级 £15–21）一律**即建即卖市场**；煤矿建成同样卖煤回血（£2–3）。铁的资源留着给陶瓷厂翻面用，别把铁厂留在板上等着慢慢烧。（依据：全场铁厂卖出记录 10+ 次，A 步 90 单笔卖 £21；反面教材 B-P0 把研发成果压成板面资产，终局 92 分。）

3. **所有高价板块必须有"卖出路径"再建**：建 1 级陶瓷厂（£17+1铁）、3 级以上棉纺、7/8 级制造厂之前，先确认自己已连通对应类型商人、且该商人尚有额度。无连通 → 先铺轨，不建厂。（依据：高分玩家高价板块卖出率 100%；B-P0 建成 5 级制造厂和 1 级陶瓷厂后均无卖出记录，沉没 £30+ 建造成本与 3 步研发成本，少 18VP——这是 92 vs 122 的直接差距。）

4. **贷款纪律：收入 <3 不贷，负收入绝不贷**：安全线为收入 ≥5 时贷款（贷后仍为正）；收入 1–4 且刚建好铁厂/酒厂即将转正时可贷一次；收入已为负时禁止再贷。（依据：安全贷款样本 A 步 43/62/83 均贷后为正、无惩罚；B-P0 步 11（2→-1）和步 28（-1→-4）负上再贷，全场最低分。A 局全员虽 R1 负贷，但只贷一次并立刻转正。）

5. **收入轨道优先用 2 级煤矿推进**：中期（C4–C8）每有 £7 富余且煤矿位可用，优先建 2 级煤矿（2VP+7收入），目标铁路时代前收入 ≥10、终局前 14–16。（依据：2 级煤矿全场出现 8+ 次，是出现频率最高的单一板块类型；胜者终局收入 14–16，折合 14–16 终局 VP，约占总分 12%。）

6. **铁路时代首动 = 双轨，且主动寻找"一次行动双卖"**：R9 第一轮铺双轨（£15+2煤+1酒，酒用自产 2 级酒厂）；之后每回合检查"是否有一条线路能让两个已翻面待售板块同时卖给同一商人"，有则优先执行。（依据：两局胜者均在 R9 首轮铺双轨；B 局 P2 步 87 陶瓷厂+3级棉纺双卖单次 19VP+8收入，是 122 分夺冠的胜负手；整局无双卖的玩家均未过 100 分。）

7. **终局三步收官法**（最后 3–4 轮）：① 收入 ≥12 时立刻贷款（-3 收入换 £30，时代末收入不再经营，零成本）；② 用贷款建 2/3 级煤矿（+6~7 收入 ≈ 6–7 终局 VP）或压轴卖出 7/8 级制造厂（11VP+商人奖励）；③ 剩余行动力补 £5 单轨刷 Link 计分。（依据：末段高收入贷款样本 A 步 110/123、B 步 92/115 全部发生在 R13 之后；2/3 级煤矿收尾动作两局共 9 次集中在最后两轮；7/8 级制造厂卖出均在 R14–R16 打出。）
