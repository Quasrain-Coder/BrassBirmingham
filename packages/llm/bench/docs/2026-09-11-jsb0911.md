## 1. 动机

0910 的酒厂 flip 地板 0.85 带来桶经济 VP（内战 +3.1），但对照实验证明
它会盖过更好的 link 决策（seq104 盖过 [27]，0908 同位置选 [27]）。
静态地板的矛盾：0.85 分高但盖路、0.6 路对但分低。

## 2. 改动（三项，均为估价层）

### 2.1 动态酒厂地板（flip.breweryRailFlipFloor/DecayWindow/LateFloor）

开局至最后 `breweryRailFlipDecayWindow`(8) 动前地板保持 0.85（早期桶必被
喝掉）；末期按比例衰减到 `breweryRailFlipLateFloor`(0.6)——除非自己有
未翻可售板块（桶确定会被用掉）则不衰减保持 0.85。桶经济 VP（早期酒厂
造出必翻）与路径正确性（末期不盖过更好的 link）兼得。

### 2.2 link 未翻建筑图标系数（network.unflippedIconCoefficient=0.6）

Link 端点的未翻面板块按系数计入未来价值——高价值未翻板块（棉/制造/陶）
大概率会翻,其图标在时代末会兑现,高手局该系数 >0.5。

### 2.3 末轮研发归零（develop.endgameZeroRound=1.5）

解锁出的板块在末轮卖不掉,白解锁——收益只剩铁的成本（回放 seq117:
末轮研发解锁 L5 无人可卖的无效动）。

另：0910 原地修——breweryRailFlipFloor 0.85→0.6（seq104 恢复 [27]）。
