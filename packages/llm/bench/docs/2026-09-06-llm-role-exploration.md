# LLM 差异化角色探索框架（③：规划 / 对手建模）（2026-09-06）

> 前提复盘（已有证据，见 argmax-architecture.md 与 round4 终版）：
> LLM 逐行动自由选择为负增量（−8~−24VP）；SHOW_SCORES 数值对齐后模型把
> 67% 的步子对齐到评分 rank0（c0 仅 29%），成绩仍为 74.7 vs argmax 89.3
> ——亏损集中在 33% 的偏离步。**「LLM 在评分器旁边做仲裁/兜底」的前提
> （偏离步有正期望）被证伪。** 任何让 LLM 参与逐行动选择的方案默认不设。
> 以下方向仅在「改变 payoff 结构」的前提下立项。

## 方向 A：开局流派承诺规划（一次性，非逐步）

假设：启发式 computePlan 是单维贪心（逐局重选流派），0903 文档 E4r-E8 证明
「无承诺的方向引导」是死路——方向加分挤掉当步最优行动。LLM 若在开局
一次性产出**跨时代承诺序列**（如"运河：铁厂×3+酒厂L2×2，铁路：棉L3 流 +
自酒双轨"），后续步仅在「评分器 Top1 与承诺冲突且分差 > 阈值」时纠偏，
则规划不与逐步评分争夺控制权，只在流派分叉点起作用。

最小实验（预期 1-2 天）：
1. runner 加 `--llm-plan`：开局第 1 步用 LLM 产出流派 JSON（产业×等级×
   时代节奏），全文注入后续步 systemExtra（"你的既定流派：…偏离需说明"）；
2. ×10 同种子对照 argmax 基线（89.3）：判定标准为均分差与"流派执行率"
   （既定产业的建造占比）；
3. 风险预案：若执行率 >60% 而均分下降（重演 E4r 单极化），方向关闭。

## 方向 B：对手意图建模（信息面，非选择面）

启发式完全不含对手手牌/意图推理（opponentResponseWeight=0 关闭）。LLM 的
差异化在于从对手已建板块+行动序列**叙述**威胁画像（"P2 在攒棉 L3 流，
它下步大概率铺 derby 运河"）。产物不是行动选择，而是**改写评分器输入**：
威胁画像注入 systemExtra 供 sell 狙击（denyLastBarrelBonus）/铺路封锁的
候选加权——仍由评分器执行。

最小实验：先离线评测（不进对局）：LLM 对 30 局中局快照产出威胁画像，
人工核对命中率；命中率 >60% 再进对局验证。

## 方向 C：复盘解说（零风险，已具备）

LLMAgent 决策链 + decisions.jsonl 已含 reason 全量——赛后复盘解说
（summarize 链路）是 LLM 当前唯一有正确定位的环节，产品化即可。

## 明确关闭的方向

- 逐行动仲裁（含"分差<ε 才咨询"）：e0 已证伪；
- prompt 具体化/数值对齐的进一步调优：d0/e0 已证伪；
- 候选重排：rank 语义下 LLM 重排就是自由选择的变体。
