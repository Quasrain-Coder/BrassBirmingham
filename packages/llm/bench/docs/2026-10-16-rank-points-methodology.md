# 评估方法改革：名次积分制（2026-10-16）

**问题**：镜像 H2H 的 56% 胜率门槛方差大、对小改进过敏——E25 greedyroll
（52.6%、人均 +2.3、四段全正）被挡在门外，微小但真实的改进永远合不进去。

**新规矩**（用户定）：4 人局 2v2（两座位新版、两座位基线），按本队两个座位的
名次组合计分：

| 名次组合 | 积分 | | 名次组合 | 积分 |
|---|---|---|---|---|
| 1/2 | 4 | | 2/3 | 1 |
| 1/3 | 2 | | 1/4 | 1 |
| 其余 | 0 | | | |

平局按密集排序（1,1,2,3）：(1,1)=4、(2,2)=1。同实力两队期望 1.333/局。

**合入规则：名次积分均值更高 且 人均 VP 更高 → 合入。不强求 55% 胜率。**
双条件拦 fluke（如 K12 人均高但积分低=抢冠军型波动，正确拦下）。
head2head.ts 已内置统计与判定输出。
