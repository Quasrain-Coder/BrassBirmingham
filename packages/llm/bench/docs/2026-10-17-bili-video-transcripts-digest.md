## 逐套路提取：触发条件 → 动序公式 → 上限 → 风险/反制

### 条1 标准铁酒（BV1DU411f7d7）
目标板子：2×二级箱 + 二级铁 + 三级铁 + 2×二级酒 ≈ 75 分（产业算两时代）+ 路分。
贷开→路铁→贷铁→研发→非粮囤酒→两箱→路铁→路卖。**蹭到两条路则省掉路卖**。

### 条2 研铁标铁（BV1bs42137Fa）
研(一级煤+一级铁)→一带一路→一铁一研(两酒)→一酒一研/一酒一箱→路铁(三级铁)
→一贷一箱→一箱一酒(三级酒)→一路一卖。
**核心警告**：研铁=被绑架必须出铁，出不了=纯白研发一动；不研铁可先做酒箱、
铁价高时随时一路一铁，保留转型三箱三酒等的余地。研发路线会留下处理不掉的
一级件（一级铁或一级箱）。

### 条3 传统路陶（BV11Z421W7d3）
贷路陶（合并行动亏 £3 利息，**防被卡**）——路连考文垂方向、陶拍斯托克（开局
需斯托克牌）→ 研两酒+一煤二陶 → 一贷一煤 → 拍两酒（**德比/斯东/纳尼顿三个
酒位最优：关联所有二时代陶位**）→ 一贷一陶（三级陶，6-8 已晚）→ 一路一酒 →
一贷一卖。上限 75 分+32 收入。二时代：五级陶 / 四级陶+一级铁研发。
风险：先连路=帮别人连、6.8 后酒位空、四贷经济易崩。对策：不稳先拍二级陶占格；
无还贷手段→提前一路一卖一级陶回经济。

### 条4 传统三棉（BV1Dw4m1i7cg）
研(一级棉+一级煤——**不研两个一级棉**，留回旋余地) → 研研(两一棉两二棉) →
一贷一棉(抢棉位) → 一贷一煤 → 一路一棉 → 一贷一路 → 一棉一酒 → 一路一卖。
75 分+20 收入；二时代三个四级棉+一级陶。
风险清单：被卡棉位（先连路手里没伍斯特则棉位可被卡）/被卡铁价（研发到三级棉
才启动，贪铁价先连路→出棉轮次置后）/被卡还贷（铁酒玩家炸铁蹭不到达德利/考文垂
煤→"直接一路一煤还贷，不要去想蹭了，早还早安心"）/被卡市场酒（末轮被喝市场
酒→要去连路喝别人酒）/二时代被背刺（蹭棉位的人二时代反卡，一桶酒只卖两棉）。
收口金句：**研发不要心疼钱，要么及时收手转铁酒要么研到底；煤蹭不到别等，路煤
先解决还贷；酒位紧张提前卖掉。**

### 条5 三箱三酒（BV1mM4m1U7H7）
研两酒（全程只研一次，铁价卡不住）→ 一酒一贷（**酒牌少→产业牌空降酒位**；
箱位牌多→空降箱子）→ 一箱一酒 → 蹭煤还贷/卖箱还贷 → 一酒一箱 → 一路一箱 →
路煤/贷路+一煤+贷煤。58 产业分+路 ≈ 70。容错极高、上限低（低级产业通病）。
酒不必三箱三酒——两箱一棉/两箱一陶皆可，**只要把自己的酒消耗掉**。

### 条6 两棉两酒（BV19x4y1t7g6）
四号位友好。路研开局（等铁价）→ 一研一酒 → 一贷一研(一级煤) → 一研一酒 →
一研一棉 → 一带一路(确保第一个卖) → 一棉一卖 = 2×三级棉+2×二级酒。
优于三棉：两酒自产自销、少连路、先酒后研**留转型窗口**、二时代可出酒保高级棉
上限；分数不低于三棉且收入轨更高。需一个安全酒位。

### 条16 路开科厂（BV1NnfbBBEp5）
四号位反击/限制打法。条件：科厂市场是箱→需有吴尔福牌，是棉→需有基德明/武斯特
牌（保证必蹭到一个产位）。核心收益=**压制研煤铁玩家**：其补铁从 8 元变 0 元
（"本来赚 8 块现在赚 0 块"）；对手一言一帖沉底→我方一带一铁封锁科厂。
本质是**顺位与对手经济的双重干预**，而非自顾自发育。

### 条17-18 无酒铁棉·四号位（BV1T4dUBsEGe）
打法一（针对研煤铁）：贷开跟在贷路铁后面 → **棉路 £15 沉底**（若对方研的
是酒酒则直接棉卖）→ 路卖抢先手 → 研铁 → 路煤 → 路铁 → 研研 → 棉棉（三级棉
塔姆沃斯稳位）→ 收入轨 10+。路网从伯明翰铺到德比，不影响二时代布局。
打法二（群友改编，更凶）：贷贷 → **绵绵 £24 沉底** → 路卖（卖两个一级棉，
**第三轮收入直接 +5 吃伯明翰收入轨——"第三轮收入抬最高的办法"**）→ 格洛斯特
研发酒研一级铁 → 路铁达德利 → **偷渡雷地奇出铁（解锁对手专属隐藏铁位）** →
研研解决煤 → 路煤 → 收入轨 12 + £30 进二时代 → "160 打底"。
二时代口诀：**一直路、煤只补高价、7-8/8-8 下两棉最后一卖。**

### 条19 无酒陶（BV1EMosBVE29，whisper 误写"五九桃"）
**一时代不喝酒直接赢**——"你压根不用出这个陶，一时代打完已经赢了，二时代
去修路就完了"。四种席位变体：①贷路铁开 ②研开(研煤铁，等前人补铁) ③研三三
煤铁 ④四号位蹭路开。核心链：陶研(研一三陶) → 路路(抢先手) → 路煤(+2) →
路陶(三级陶，沉底 6-8) → 路路/路煤/路卖收尾。一时代 60-70 分常态、极限逼近
100（vs 对手六七十分）。条件：市场=斯托克或伯明翰万能+德比侧陶市场；手牌=
铁/德比 + 斯托克 + 陶产 + 煤牌。弱点：点位全在上半区，伯明翰侧要尽早落位
（或飞煤下来），否则二时代修路受限。

### 条20 新无酒三棉（BV1LV5u6xEUN）
**触发条件（可照抄的检测器）**：必须 3 号位；前两家一家贷、一家必须研煤铁
（研酒的不行——"卡铁价卡死"）；伯明翰最好无棉市场（有则可能被 4 号位飞一级棉
卡，但套路有通市场 Plan B，被卡也能玩；万能市场基本不被卡）。
**动序公式**：研研(一二级棉全研) → 贷棉(拍伯明翰抢棉位) → 路路(抢手动) →
路煤(收入回正一) → 路棉德比(购棉市场酒) → 6-8 沉底 → 7-8 贷路抢先手 →
8-8 贷路棉卖(**第一个卖**)。牌需求：**三张棉箱牌+一张煤牌即可"报杀三家铁酒"**。
实况验证：82 分压三家超模标铁（78/80/73）。"市场七分+铁定无同行=天然强"。
二时代：回经济优先（**能晚贷一轮是一轮**；塔莫斯煤位保节奏，不贪 1 分路点）、
最后两棉一卖；三/四级棉+一陶可四卖。

### 条21-23 0贷流（BV1K7416kEui）
旧版研 2-2 煤箱开局 → 环境变化后新版**路开**（伯明翰只能路开那一条）。
路铁研(一煤一箱) → 路煤(+5) → 路煤/路铁(+7) → 铁箱(翻铁,+11) → 路箱(+11) →
路卖(+13) → **二时代 £25+13 收入开局"非常豪华"**，板子 2-2煤 2-2箱 2-3铁
（标准无酒板）扎实、六条路每条 6 分打底。
变体·零贷高箱（铁价低卡壳时）：**研发拖贷款**——"铁价低你就研，研发基本不
花钱，收入大于研发，等于白等一轮收入"，拖到凑 £20 卖六级箱（不吃煤铁）→
收入轨卡 14。变体·零贷高棉：少一研多一路，市场最后通（防被偷酒）。
金句：**"零贷流的经济路线非常丝滑"**——贷款是工具不是禁忌，节奏才是本体。

### 教学引（BV1Jr421E7Cj）
底层逻辑：**酒的数值碾压**（二级酒 vs 二级铁 5分3收 / 二级箱 5分1收 / 二级棉
5分4收，酒还最便宜）→ 线上打法先抢酒位。新手误区=喝市场酒（要翻自己的酒）。
不研一级铁（研了必须出=被绑架；一级铁 5分5收 vs 二级铁 10分1收≈等效，各有
优劣）。**一时代收入≈分数**（几百把实证）。少连路能蹭就蹭（但纯路分 30 分流
上限不如产业）。**每人至少抢两个酒位**。别让别人蹭（铁路避开达德利 2 牌/
考文垂 3 牌方向）。

## 对 AI 的优化方向（按可落地度排序）

1. **顺位控制（沉底/抢先手）——全新的一阶维度，现 AI 完全没有。**
   多个套路的核心机制是"本回合花费→下回合顺位"的主动控制：棉路 £15/绵绵 £24
   刻意沉底、6-8 沉底→7-8 抢先手→8-8 第一个卖、"第三轮卡住顺位不让他沉底"。
   → E31 候选：roundPhase 加入顺位期权价值（花费节奏作为手段而非纯成本）。
2. **收入轨爬坡速度权重**：无酒铁棉"第三轮收入+5"、0贷流"二时代 £25+13"、
   教学引"一时代收入≈分数"——era1 的 income 价值接近 1VP/级（现 0.3）。
   → 做 era 分段权重（era1 高/era2 低）实验，而非全局调。
3. **"研发拖贷款"tempo 工具**：铁价低时研发≈免费等一轮收入——E29 金钱燃烧
   的姊妹机制（花钱/不花钱的节奏都是资源）。
4. **隐藏点位/偷渡**：格洛斯特研发酒→雷地奇出铁"解锁对手专属铁位"——网络
   规划里加"对手垄断点位的解锁价值"。
5. **反制层**：路开科厂（压研煤铁经济）、卡顺位防沉底、棉位被卡后的通市场
   Plan B——现 interference 雏形之上加顺位反制。
6. **playbook v2 检测器素材**：每套路的触发条件已结构化（座位号/前家开局
   类型/市场结构/手牌需求），无酒三棉的条件最完整可直接编码。
7. **编码共识表**：上面术语表应并入 prompt/审计口径，避免 LLM 侧误读。
