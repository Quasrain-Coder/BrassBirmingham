## 失败模式（本档案的核心价值）

1. **非可加性**：单项过线的改动合体必翻车（v905 三组 46%、E21 组合 9-11）。
   收益来源重叠（都在修正"次优 tempo 行动"）——叠加即重复计费。
   **规则：任何组合必须单独消融，禁止"两个都好所以一起上"。**
2. **噪声淹没信号**：rollout 独立随机流下两候选均分差 std≈10VP vs margin=3.0
   → ~38% 翻盘改选是纯噪声（E17 70%→E18 56.7% 稀释的机理）。
   **规则：推演类改动的 margin/门槛必须对照差值方差校准，不能拍脑袋。**
3. **加深≠加准**：K12 加 K 不重校 margin，成本翻倍点估计反负。
4. **方差削减≠收益**：CRN（E19）把噪声削了，但行为退化回 ≈无 rollout（50%）——
   先问"信号在哪"，再问"噪声多大"。
5. **重复计费**：MaxN 扣减（E20）与启发式已有的稀缺性定价
   （scarcityBonus/opponentsUnflippedVpAt）重叠，w 越大人均越差。
   **规则：加新评估项前先盘点现有评分里已覆盖同信号的项。**
6. **种子/座位方差 >> 配置效应**：×20 批的段间极差 ±3 局；50% vs 56.7% 在
   n=20 下不可分（CI ±22%）。**E22 实证升级：正信号同样被种子方差吃掉**——
   E17 70%×20 → E18 56.7%×120 → E22 46.9%×500 三级坍缩，E18 是种子带
   （9300-9339）运气。E25 第二次实证：E24 56.3%×120 → E25 52.6%×500。
   **校准：×120 需 ≥58-60% 才值得 ×500（两次 56.x%×120 均坍缩到 ≤53%）。**
   **规则：×20 只筛方向，×120 才是边界信号起点，
   切默认裁决只有 ×500 级别可信；跨种子带复验才算独立样本。**
7. **平台期识别**：四连败（K12/E19/E20/E21）+ 两个悬置边界信号 → 0903 是
   该架构局部最优。**规则：连续 ≥3 个系统性否决即停旋钮层，转结构性改动
   （推演策略/终止条件）或收工定版。**

## 过程教训（防坑）

- **tuneEnvVar 每版本必须唯一**（0903 文档 E1-E6 全废的事故）；消融前先
  100 倍量单局验证调参只作用于目标版本。
- **启动配置必须落盘**（/tmp/tune-*-config.txt 连同日志）——K12 的
  BRASS_TUNE7 JSON 随会话中断丢失，只能靠标签推断。
- 4 段并行 4 核：~10.5-13min/局（rollout 开）/ ~2.5min/局（无 rollout），
  规划批次时长用这两个数。
- nohup 起跑的分段进程在后端重启中存活（已两次验证），长批可放心过夜。
